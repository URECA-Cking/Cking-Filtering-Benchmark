# 2차 댓글 분류 실험 결론 (2026-10-02)

평가 대상은 댓글 본문 하나를 입력받는 기존 KOLD 모델과 DKTC 소량 보강 모델(`dktc-gap-v1`)이다. DKTC 보강은 Codex가 잠정 라벨을 붙인 `BLOCK` 13건과 합성 `PASS` 12건을 KOLD 일부와 섞어 추가 학습한 탐색 실험이다. 임계값 0.95는 개발셋에서 정한 뒤 별도 도전 세트와 `final` 평가에 사용했다. 학습·평가 원문과 점수 파일은 Git 제외 경로에 있다.

| 세트·구성 | 부적절 댓글 차단 | 정상 댓글 오차단 |
| --- | ---: | ---: |
| 개발 109건: 1차+KOLD | 33/41 | 2/68 |
| 개발 109건: 1차+DKTC | 35/41 | 2/68 |
| 별도 합성 48건: KOLD 단독 | 2/21 | 0/27 |
| 별도 합성 48건: DKTC 단독 | 9/21 | 0/27 |
| `final` 47건: 1차+KOLD | 12/19 | 0/28 |
| `final` 47건: 1차+DKTC | 12/19 | 0/28 |

**DKTC 보강의 개선 신호는 실제로 있었다.** 개발셋에서는 기존 조합보다 위반 댓글 2건을 더 잡았고 새 오차단은 없었다. 별도 합성 도전 세트에서는 모델 단독 탐지가 2/21에서 9/21로 늘고 오차단은 0/27로 같았다. DKTC 체크포인트는 다음 연구 실험의 후보로 보존한다.

다만 `final`에서는 두 조합이 같은 댓글을 차단했고, 협박 0/2와 비꼼 0/2였다. 따라서 **운영 모델로 DKTC가 우월하다고 확정하지는 않는다.** `final`의 표본이 작고 라벨이 사람 검증 전이라 결과는 개선 신호의 재현 여부를 판단하는 데 제한적이다. 현재 2차 모델 어느 것도 운영 성능을 입증하지 못했고, 1차 API 제거도 결정하지 않는다.

## 다음 데이터 실험의 조건

1. `final` 47건은 이미 한 번 사용했으므로 다음 모델의 학습·임계값 조정·선택에 쓰지 않는다. 다음 실험에는 학습 전에 새로운 독립 평가 묶음을 따로 만든다.
2. **댓글 한 줄**에 직접 `BLOCK/PASS`를 붙인 자료를 모은다. 추적·감시·사생활 노출형 위협과 그 표현을 쓰는 정상적인 안전 조언, 인용·신고, 비꼼·정중한 비판을 함께 담는다. 같은 문장이나 원출처의 근접 중복은 분할을 가로지르지 않게 한다.
3. Codex의 제안 라벨과 사람 확인 라벨을 구분한다. 공개 데이터의 `threat` 같은 범주명이나 대화 전체 라벨을 서비스 `BLOCK`으로 자동 전환하지 않는다.
4. 확보한 댓글 수준 자료의 양과 품질을 먼저 점검한 뒤에만 새 학습 코드를 돌린다. 비교에는 기존 1차+KOLD와 개선 신호가 있었던 1차+DKTC를 모두 기준선으로 둔다.

공개 후보 [Toxic_comment_data](https://github.com/songys/Toxic_comment_data)는 영화 리뷰 9,999건 학습 파일에 `threat=1`이 33건뿐이었다. 직접 확인한 양성 행에는 영화 내용 설명·정치적 문장·비유적 표현 등이 섞여 있어 현재 부족한 크리에이터 댓글 위협을 채우는 대량 학습 자료로 쓰기 어렵다. 원본은 `data/raw/toxic_comment_data/`에만 두며 Git에 올리지 않는다. DKTC도 [대화 단위 라벨과 비상업적 이용 조건](https://github.com/tunib-ai/DKTC) 때문에 운영용 댓글 라벨로 바로 사용할 수 없다.
