# 로컬 전용 필터 채택 결정과 실험 결과 (2026-10-06)

이슈 #17의 결론 문서다. 1차 OpenAI Moderation API를 제거하고 **로컬 규칙 + 로컬 2차 모델**만 사용하는 구성을 채택한다. 이 결정은 아래 평가 범위 안의 근거이며, 운영 성능 보증이 아니다. 평가 세트는 대부분 합성 문장이고 라벨은 사람 검수 전이다. 문장 원문과 점수 파일은 Git 제외 경로(`data/restricted/`, `results/`)에만 둔다.

## 모델 구성과 학습 데이터

`threat-ctx-v1-reviewed`는 두 단계로 만들었다.

1. **KOLD-only 기반 모델**: `beomi/KcELECTRA-base`를 KOLD로 3에폭 학습했다. 라벨은 `OFF=false`를 정상(0), `OFF=true`이면서 대상이 개인·집단인 댓글을 공격(1)으로 둔 학습용 근사치다. KOLD 시험셋 F1은 0.83이며 참고 지표다.
2. **위협 데이터 보강**: 위 모델 위에 소량 데이터를 얹어 1에폭 추가 학습했다.

| 보강 데이터 | 건수 | 라벨 상태 |
| --- | ---: | --- |
| DKTC 협박 대화에서 고른 발화(BLOCK)와 직접 쓴 정상(PASS) | 25 (BLOCK 13, PASS 12) | Codex 잠정, 사람 검수 전 |
| 위협·정상 대조 합성 쌍 (`threat_context_v1`) | 69 (BLOCK 34, PASS 35) | 사람 확인(`approved`) |

- 대조 합성 72건 중 3건을 제외했고, 확인 과정에서 라벨을 바꾼 행과 문장을 고친 행은 없었다. 제외로 3쌍은 한쪽만 남았다.
- 보강 데이터는 12번 반복했고, 기존 능력 유지를 위해 KOLD를 클래스당 500건 섞었다. 학습률 5e-6, 배치 8, 최대 길이 192, seed 17이다.
- 학습 입력에 평가 문장이 섞이면 중단되는 검사를 통과했다. 보호 목록에는 `final`, 갭 챌린지, 위협 평가셋 v2·v3, 위협 홀드아웃이 포함된다.
- 검수는 일반 합성 문장 기준이다. 라벨이 사람 확인을 거친 것은 69건뿐이고, 모델 전체가 사람 검수 데이터로 만들어진 것은 아니다.

## 후보 모델 비교

모두 임계값 0.95다. "1차+모델"은 저장된 1차(API+규칙) 결과와 합친 값이다.

**개발 109건 (BLOCK 41, PASS 68)**

| 모델 | 모델 단독 | 정상 오차단 | 1차+모델 | 정상 오차단 |
| --- | ---: | ---: | ---: | ---: |
| KOLD-only | 26/41 | 0/68 | 33/41 | 2/68 |
| DKTC 보강 (`dktc-gap-v1`) | 30/41 | 1/68 | 35/41 | 2/68 |
| 채팅 욕설 혼합 (`chat-mix-a2`) | 12/41 | 1/68 | 30/41 | 3/68 |
| 위협 보강 (`threat-ctx-v1`) | 34/41 | 1/68 | 38/41 | 2/68 |
| **위협 보강, 검수 반영 (`threat-ctx-v1-reviewed`)** | **34/41** | **0/68** | **38/41** | 2/68 |

**갭 챌린지 48건 (BLOCK 21, PASS 27), 모델 단독**

| 모델 | 차단 | 위협 | 비꼼 | 정상 오차단 |
| --- | ---: | ---: | ---: | ---: |
| KOLD-only | 2/21 | 0/12 | 2/9 | 0/27 |
| DKTC 보강 | 9/21 | 6/12 | 3/9 | 0/27 |
| `chat-mix-a2` | 0/21 | 0/12 | 0/9 | 0/27 |
| `threat-ctx-v1` | 13/21 | 9/12 | 4/9 | 0/27 |
| `threat-ctx-v1-reviewed` | 12/21 | 8/12 | 4/9 | 0/27 |

해석은 다음과 같다.

- 채팅 욕설 데이터(약 19.6만 건, 거친 라벨)를 섞은 학습은 두 평가 모두 기존보다 나빠서 채택하지 않았다. 원인은 확인하지 못했다.
- `threat-ctx-v1`과 `-reviewed`의 차이는 개발셋 정상 1건, 갭 챌린지 위협 1건이다. 오차 범위라서 성능 차이로 읽지 않는다. 사람이 확인한 데이터를 쓴 쪽을 채택했다.
- 위협 데이터는 개발셋에서 놓친 유형을 보고 설계했다. 개발셋과 갭 챌린지 결과는 그만큼 낙관적일 수 있다.

## `final` 47건 확인 (한 번)

모델 선택은 개발셋과 갭 챌린지로 끝낸 뒤, 선택한 한 모델만 `final`에 한 번 돌렸다. 이 결과로 모델이나 임계값을 바꾸지 않았다. 이로써 `final`은 소비됐다.

| 구성 | 차단 (BLOCK 19) | 정상 오차단 (PASS 28) |
| --- | ---: | ---: |
| 1차만 | 5/19 | 0/28 |
| KOLD-only 단독 / 1차+모델 | 10/19 / 12/19 | 0/28 |
| `threat-ctx-v1-reviewed` 단독 / 1차+모델 | 12/19 / 13/19 | 0/28 |

협박은 1/2, 비꼼은 0/2가 잡혔다. 표본이 작아 1건 차이는 우연일 수 있다. 개선의 방향만 확인한 것이다.

## API 호출 대 미호출 비교 (신규 204건)

기존 평가셋은 위협에 치우쳐 API의 기여를 보기 어려웠다. 인스타·유튜브 댓글 말투로 정상 100, 위반 98(욕설 27, 혐오 20, 스팸 19, 개인정보 13, 위협 19), 경계 6건을 새로 만들었다(`data/restricted/social_eval_v1.jsonl`). 문장은 Claude가 쓴 합성이고 라벨은 잠정이며, 기존 데이터와 80% 이상 비슷한 문장은 제외했다. 학습·임계값·모델 선택에 쓰지 않는다.

1차 결과의 근거(`reasons`)에서 API 판정(`model`)을 빼면 API 없는 구성을 재현할 수 있어, API를 1회 호출한 결과로 모든 구성을 계산했다.

| 구성 | 차단 (98) | 정상 오차단 (100) |
| --- | ---: | ---: |
| 규칙만 | 24 | 0 |
| API만 | 30 | 2 |
| 로컬 모델만 | 61 | 1 |
| **규칙 + 로컬 모델 (API 미호출)** | **78** | **1** |
| API + 규칙 + 로컬 모델 (API 호출) | 78 | 3 |

- API가 단독으로 더한 위반은 **0건**이었고 정상 오차단은 2건 늘었다. 한국어 관용 표현("죽여준다", "죽도록")을 위협으로 본 사례다.
- 유형별 규칙+모델: 욕설 27/27, 혐오 20/20, 위협 15/19, 개인정보 10/13, 스팸 6/19.
- 이 평가셋에는 노골적 성적·폭력·자해처럼 API가 강한 유형이 거의 없다. 결론은 "이 서비스의 위반 유형에서는 API가 불필요했다"까지다.

## 범위 결정

- 이번 필터는 욕설·혐오, 스팸, 개인정보, 알려진 위협 패턴을 자동으로 거른다.
- 문맥이 있어야 판단되는 위협, 비꼼, 새 은어는 이후 **신고 → 사람 검수 → 추가 학습** 경로로 보완한다. 신고를 그대로 라벨로 쓰지 않고 검수 후에만 학습 데이터로 쓴다.

## 평가 도구 사용 시 주의

- `eval_full_dev`는 출력의 모델 이름을 코드에 고정한다. 첫 번째 칸은 항상 `kold`(`--base-model`), 두 번째 칸은 항상 `dktc-gap-v1`(`--dktc-model`)로 표시된다. `--dktc-model`에 다른 모델을 넣으면 그 모델 결과가 `dktc-gap-v1` 라벨로 나오므로 리포트에서 이름을 바로잡아야 한다.
- `eval_gap_challenge`는 `--candidate-model`의 상위 폴더 이름을 모델 이름으로 쓴다. 폴더명과 리포트의 이름이 같은지 확인한다.
- 두 스크립트 모두 기존 출력 파일이 있으면 중단된다. 같은 이름으로 다시 돌릴 수 없다.

## 데이터 이용 조건

- DKTC는 CC BY-NC-SA 4.0(비상업적 이용 조건)이며 최종 모델의 보강 데이터 25건에 포함된다. 서비스에 배포하려면 이용 조건이 허용하는지 먼저 확인해야 한다.
- 채팅 욕설 데이터(CC BY-NC-SA 4.0)는 채택한 모델의 학습에 쓰이지 않았다.
- KOLD의 이용 조건은 이 문서 작성 시 확인하지 않았다. 배포 전에 확인한다.

## 재현 순서

학습과 평가는 Git Bash에서 직접 실행한다. 출력 폴더와 파일은 새 이름이어야 한다.

```bash
# 보강 학습: DKTC 25건 + 검수 69건
python -m src.train_dktc_gap_classifier \
  --approved data/restricted/dktc/provisional_comments.jsonl \
            data/restricted/threat_context_v1_reviewed.jsonl \
  --output-dir results/kold-classifier/threat-ctx-v1-reviewed

# 개발 109건, 갭 챌린지 48건
python -m src.eval_full_dev --dktc-model results/kold-classifier/threat-ctx-v1-reviewed/best \
  --output results/full-dev/threat-ctx-v1-reviewed-scores.jsonl
python -m src.eval_gap_challenge --candidate-model results/kold-classifier/threat-ctx-v1-reviewed/best \
  --output results/gap-challenge/threat-ctx-v1-reviewed-scores.jsonl
```
