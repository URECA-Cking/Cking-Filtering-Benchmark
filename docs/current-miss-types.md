# 현재 파이프라인의 미탐 유형 점검 (2026-10-02)

기준: 저장된 1차 판정과 `dktc-gap-v1` 2차 점수, 임계값 0.95. 추가 API 호출·재추론 없음. `dev` 109건, 이미 사용한 `final` 47건, 별도 합성 도전 48건. 평가 문장은 대부분 합성이며 라벨은 사람 검수 전이다. `final`은 유형을 진단할 뿐 새 학습·임계값 조정·모델 선택에 재사용하지 않는다.

## 이번 데이터 작업의 확정 범위

- **1순위:** 크리에이터에게 직접 향하는 방문·추적·감시·사생활 노출 위협. 다음 데이터 묶음은 이 유형과 짝을 이루는 무해한 댓글부터 만든다.
- **2순위:** 명확한 직접 비하와 집단 배제. 표본이 적으므로 새 댓글 수준 사례를 확보해 확인한다.
- **보류:** 비꼼을 일괄 BLOCK으로 학습시키는 결정. 현재 레이블만으로는 정당한 비판과의 경계를 확정할 수 없다.

이는 저장된 평가에서 관찰한 **작업 우선순위의 확정**이다. 개별 평가 문장의 잠정 레이블이나 실제 배포 성능을 확정한 것이 아니다.

| 누락 유형 | dev 누락 / BLOCK | final 누락 / BLOCK | 별도 도전 세트의 2차 모델 누락 / BLOCK |
| --- | ---: | ---: | ---: |
| 추적·방문·암시적 위협 (`threat`) | 3/4 | 2/2 | 6/12 |
| 비꼼·우회적 조롱 (`sarcasm`) | 3/4 | 2/2 | 6/9 |

| 약한 집단 일반화 (`weak_hate`) | 0/4 | 1/2 | 해당 없음 |
| 그 밖의 배제 표현 (유형 미지정) | 0/9 | 1/3 | 해당 없음 |

`final`의 전체 BLOCK 미탐은 7/19로, KOLD와 DKTC 보강 모델이 동일한 사례를 놓쳤다. dev는 DKTC 보강 모델 기준 6/41 미탐이다. 별도 도전 세트는 2차 모델 단독 평가이므로 파이프라인 수치와 직접 합치지 않는다.

## 우선순위와 실제 문장 형태

1. **방문·추적·감시·노출 위협:** 주소를 안다고 하며 방문을 예고하거나, 이동 경로·출입문을 지켜보겠다고 말하거나, 사진·연락처 공개를 조건으로 행동을 강요한다. 명시적 폭행 단어가 없어 1차와 2차가 모두 낮은 점수를 준 사례가 많다. 예: `ctx-threat-05b`의 2차 점수 0.001685, `gap-threat-b02` 0.001067.
2. **비꼼:** 겉으로는 축하·칭찬·존댓말이지만 맥락상 상대를 낮춘다. `final` 2/2 미탐, dev 3/4 미탐. 다만 일부 문장은 정당한 비판과 경계가 불명확하다. 이 범주를 대량 BLOCK 학습 데이터로 만들기 전에 서비스 기준에 따른 사람 검수가 필요하다.
3. **약한 비하·집단 배제:** 직접 대상을 낮추지만 욕설은 없는 짧은 문장. `final`에서 직접 비하 1건, 집단 일반화 1건, 장애 관련 배제 1건을 놓쳤다. 표본이 작아 일반화하기 어렵다.

## 오차단

dev에서 PASS 2/68을 차단했다. 모두 1차에서 이미 BLOCK이었다: 부적절한 말을 **인용해 문제 삼은 댓글** 1건과 **친근한 농담** 1건. 2차 모델만 바꿔서는 이 두 건의 파이프라인 판정이 바뀌지 않는다. `final`에서는 PASS 0/28 오차단이었다.
